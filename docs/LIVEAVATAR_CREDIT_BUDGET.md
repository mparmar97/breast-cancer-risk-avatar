# LiveAvatar credit budget (Starter)

## Defaults in this repo

| Setting | Value | Why |
|---------|-------|-----|
| `LIVEAVATAR_MODE` | `LITE` | **1 credit/min** (FULL is 2/min). Groq LLM + Groq TTS; LiveAvatar lip-syncs video. |
| `LIVEAVATAR_SANDBOX` | `false` | Doctor avatar (Ann Sitting). Uses credits — keep demos ≤120s. Set `true` only for free Wayne testing. |
| `LIVEAVATAR_DEV_MAX_SESSION_SECONDS` | `120` | Caps each session at ~2 minutes (Starter hard cap is ~5 min). |

LITE audio: Groq TTS PCM is played **in the browser** so you hear the voice, and the same PCM is sent to LiveAvatar for lip-sync.

## Budget plan (~150 credits)

Reserve **10–15 credits** for three meaningful demos:

| Demo | Duration | LITE cost |
|------|----------|-----------|
| Interaction 1 | ~2 min | ~2 |
| Interaction 2 | ~2 min | ~2 |
| Interaction 3 | ~2 min | ~2 |
| Margin | — | ~4–9 |
| **Reserved total** | | **~10–15** |

Do **not** leave long idle sessions running. End avatar as soon as the ~2 minute path finishes.

For zero-credit local UI work only, temporarily set `LIVEAVATAR_SANDBOX=true` (Wayne).

## Pipeline (LITE)

```
User (text or Talk mic)
  → Worker: adaptive dialogue + Groq LLM (medical text)
  → Worker: Groq Orpheus TTS → PCM 24 kHz
  → LiveAvatar LITE: lip-sync video only
```

Medical content is never generated by LiveAvatar.
